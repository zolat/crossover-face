# Colour Field Lab

Interactive browser prototype for comparing and tuning Crossover Face colour
palettes. Activity, Beacon, and Pulse mirror shipping watch themes; Arcade
remains the mockup-only candidate.

## Run locally

```sh
npm install
npm run dev
```

## Features

- live awake, always-on, and temperature-range dial rendering
- editable ring colours and ring-order controls
- explicit cold, middle, and hot ramp selection
- adjacent-ring CIELAB distance and weighted brightness feedback
- side-by-side candidate board and copyable palette output

Use `npm test` to build and verify the rendered palette lab.
